# Data Structure

数据结构是离散数学在编程实现上的延伸。南京大学开设的数据结构每周都会有三道改编自[leetcode](https://leetcode.cn/problemset/)的编程作业，另加三次上机测验（测验难度稍难于作业题）。编程能力不强的同学强烈建议移步[此处](https://www.acwing.com/activity/content/11/)学习（不是卖课，本人和若干优秀的学长们倾情推荐☀️）

## 如何学好这门课？
来讲一讲笔者自身惨痛的经历。  
笔者在大一下学习了[CS61B](https://github.com/retiaw/NJUCS/blob/main/CS61B.md)，自以为应对数据结构已经手拿把掐，于是期中喜提全班倒数的好成绩。下半学期痛定思痛，开始学习**教材、ppt**，总评才保住了90））  
1. 要把这门课程的学习当作应试的话，考试前一定要和ppt对齐颗粒度
2. 对于笔试，不需要大量刷题，考试之前[过拟合](https://zh.wikipedia.org/zh-cn/%E9%81%8E%E9%81%A9#:~:text=%E5%9C%A8%E7%BB%9F%E8%AE%A1%E5%AD%A6%E4%B8%AD%EF%BC%8C%E8%BF%87,%E5%81%8F%E5%B7%AE%E5%B0%8F%E8%80%8C%E6%96%B9%E5%B7%AE%E5%A4%A7%E3%80%82)到作业题上即可
3. 对于机试，推荐刷与所讲内容相关的leetcode。个人感觉[luogu](https://www.luogu.com.cn/)中题目的变式较多，对于非OIer不太友好，很难刷出手感
